# Assets Directory

This directory contains app assets including icons and splash screens.

## Required Assets

Before building the app, you need to add the following assets:

- **icon.png** - App icon (1024x1024px)
- **adaptive-icon.png** - Android adaptive icon foreground (1024x1024px)
- **splash.png** - Splash screen image (1284x2778px recommended)
- **favicon.png** - Web favicon (48x48px)

## Generating Assets

You can use tools like:
- [Figma](https://figma.com) for design
- [Icon Kitchen](https://icon.kitchen/) for generating app icons
- [App Icon Generator](https://appicon.co/) for multi-platform icons

## Colors

Primary brand color: **#10b981** (Emerald green)
